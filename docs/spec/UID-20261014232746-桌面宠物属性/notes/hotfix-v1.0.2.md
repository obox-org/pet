# 热修记录 · pet v1.0.2（周期调整）

关联 change：`pet-desktop-companion`（已归档 `2026-10-16-pet-desktop-companion`）｜UID：`UID-20261014232746-桌面宠物属性`｜日期：2026-10-16

> 记录 **v1.0.1 发版后**由用户裁定的一处**参数调整**。与 v1.0.1 不同，这次**不是**"实现与规格不符"，而是**用户明确改判**：已归档规格里写的是"每 10 秒随机表演一轮"，用户实机体验后要求改为"**每分钟一次**"。

## 1. 触发与裁定

| 项 | 内容 |
| --- | --- |
| 用户原话 | "pet扩展每次动画只播放一次，间隔1min播放一次，而不是10s钟播放一次" |
| 父代理解读（已按此执行） | **只改周期**：10 秒 → **60 秒**；"每次动画只播放一次"是既有行为的重申（每次触发只播一轮，v1.0.0 起即如此），无需改动 |
| 与归档规格的关系 | 归档的 `specs/pet-sprites` 与 `design.md` D-14 写的是**每 10 秒**；本次为**用户改判**，已在两处归档文本加"v1.0.2 修订"标注（保留原文，不篡改历史），**实现以本记录与代码为准** |
