# 21 · host-ai-options（宿主：设置页新增「AI」选项）

| 字段 | 内容 |
| --- | --- |
| **目标** | 在宿主设置里新增内置页**「AI」**，可配置 OpenAI 兼容接口参数：**baseUrl / apiKey / model / contextLen / 每日限额（可为空）**，并提供**「测试连接」**按钮验证配置可用。 |
| **用户原话** | "obox增加AI选项，可以配置openai的接口参数，包括baseUrl、apikey、model、contextLen和每日限额，每日限额可以为空"。用户选定范围（Q19=A）：**配置页 + 掩码 + 测试连接**；`dailyLimit` 本期**只存储 + 展示**（无消费者，不做用量记账）；**不新增扩展 API 面**。 |
| **父代理的范围裁定（重要）** | 为兑现 Q19=A 里"不动 `apiVersion` 门槛"，**API key 的掩码做成 AI 页内的专用控件**（不新增公开的 `password` 字段类型）。理由：新增 `SettingFieldType` 属**扩展可见能力** ⇒ 按仓库惯例（`progress` 随 apiVersion 2 引入）必须 bump `apiVersion` 到 3，并联动 `contributions.ts` 文档 / `scripts/validate-manifest.mjs` 白名单 / `test/manifest-script-parity.test.ts` / `manifest-reference.md` / `themes-settings.md` —— 那是**另一个 change**。若用户日后要让扩展声明掩码字段，再单开（届时一起 bump apiVersion 3）。请在回执里确认你按此执行、未改 `src/api/contributions.ts`。 |
| **输入/现状（已查实）** | 设置页是**内置扩展** `src/renderer/src/extensions/settings/`（`manifest.json` 的 `navItems[settings.main]` → `view: "SettingsView"`；`index.ts` 导出 `SettingsView`）；左侧树是**硬编码页键**（`SettingsView.vue:23-32` 的 `TreeKey`：`appearance` / … / `update` / `network`，另有 `extensionPages`），右侧按 `v-else-if="active === '…'"` 分块渲染（`:644/:752/:811`）；文案在 `src/renderer/src/i18n/locales/{zh,en}.ts`（`settings.update`/`settings.network` 等）；设置值统一走 `stateStore`（localStorage），引用时必须留意 reactive Proxy 进 IPC 的问题（`core/plainProxy.ts` 的既有教训）。 |
| **文件所有权** | `src/renderer/src/extensions/settings/SettingsView.vue`、`src/renderer/src/i18n/locales/**`、`src/main/**`（新增测试连接的 IPC 实现，可新建 `src/main/ai.ts`）、`src/main/index.ts`（注册 IPC）、`src/preload/index.ts`、`src/shared/types.ts`（MainApi）、`test/**`、`README.md`、`docs/adr/`（**新增 ADR-0025**）。**不含**：`src/api/**`（不得新增扩展 API/字段类型）、`scripts/validate-manifest.mjs`、`docs/extension-api/**`（本次无扩展可见面变化——请在回执里明确这一判断）。 |
| **实现要求** | ① **左侧树新增页「AI」**（`TreeKey` 加 `'ai'`；树节点位置建议在「更新」「网络」之后；i18n `settings.ai` 中英各一份，中文「AI」，英文「AI」）；② **页内五个字段**（一律走 `stateStore`，键名前缀 `ai.`）：`ai.baseUrl`（text，占位 `https://api.openai.com/v1`）、`ai.apiKey`（**掩码**：默认显示为圆点/星号，旁边一个「显示/隐藏」切换按钮，切换只影响显示、不改值；空值允许）、`ai.model`（text，占位如 `gpt-4o-mini`）、`ai.contextLen`（number，默认给一个合理值如 `8192`，非法/空按默认）、`ai.dailyLimit`（number，**允许为空 ⇒ 存 `null`/空串表示"不限"**，UI 上留空不报错、旁边用描述文字说明"留空表示不限"）；③ **「测试连接」按钮**：用当前配置发一次**最小请求**（建议 `GET {baseUrl}/models`，带 `Authorization: Bearer <apiKey>`），**必须在主进程用 `netSession()` 发起**（⇒ 自动继承宿主代理与忽略 SSL 设置，与 `api.net.fetch` 同一 session；不要用渲染进程的 `fetch`，那走默认 session、不经我们的代理）；结果用**中文**反馈：成功显示"连接成功（N 个模型可用）"或列出前几个模型名；失败显示可执行原因（缺 baseUrl / 401 密钥无效 / 404 地址不对 / 网络或代理错误 / 超时）；请求要带**超时**（如 10 秒）且**不阻塞 UI**（按钮进 loading 态）；④ **不做**：不做用量记账、不校验 key 有效性以外的语义、不把 key 用于任何实际调用（本期无消费者）；⑤ **安全口径**：key 明文存在 localStorage（与其它设置一致）⇒ 必须在页内**明示**这一点（一行小字：以明文保存在本机配置中），并在 ADR-0025 记录该取舍与退场条件（将来若要系统级加密，用 Electron `safeStorage`，属独立改动）。 |
| **验收命令** | ① `npm run typecheck` 0 error；② `npm run lint` 0 error（既有 4 条 warning 不增；改前删 `.eslintcache`）；③ `npm test` 全绿（基线以卡 20 合并后的数字为准，预计 **793+**）；④ **新增测试**：i18n 中英键**一一对应**（仓库既有这类门禁就复用；新键必须两侧都有）；`ai.dailyLimit` 为空 ⇒ 存空且不报错、填非数字 ⇒ 拒绝或归一（按你选的策略并写明）；测试连接 IPC 的**请求构造**（用可注入的假 fetch/session）：baseUrl 拼接（含/不含尾斜杠都要正确）、`Authorization` 头、超时、错误分支（401/404/网络/缺 baseUrl）各自的中文文案；**掩码不泄漏**：断言渲染层默认不把 key 明文写进 DOM（可读源码/快照断言）。⑤ **实机验证（写进回执）**：起 dev 宿主 ⇒ 设置 → AI ⇒ 五项可填可保存、重启后保留；掩码默认隐藏、点「显示」可见；`每日限额` 留空可保存；「测试连接」在**故意写错 baseUrl** 时给出中文失败原因、在正确配置下成功（若你手头没有可用 key，可用一个**本地/公开**的 OpenAI 兼容端点或明确记录"未实机验证 HTTP 成功路径（无可用 key），以单测覆盖请求构造"——如实标注，不要编造）。⑥ `git status` 只含所有权内文件；**不要提交**（父代理负责 PR）。 |
| **文档同步（AGENTS 强制）** | 新增 `docs/adr/0025-host-ai-options.md`（背景：用户要 AI 配置；决策：五个设置键 + 掩码控件 + 主进程测试连接（复用 netSession ⇒ 走代理）+ dailyLimit 只存储不记账 + key 明文存储的取舍与退场条件；备选与否决理由：新增公开 `password` 字段类型⇒需 bump apiVersion 3、系统级加密⇒safeStorage 另开、渲染进程 fetch⇒不经代理）；`README.md` 的文档导航/设置说明处补一句"AI 选项（OpenAI 兼容参数 + 测试连接）"。`docs/extension-api/**` **无需**改动（无扩展可见面）——回执里明确写出该判断。 |
| **负向自检** | baseUrl 为空点测试 ⇒ 中文提示"请先填写 baseUrl"，不发请求；baseUrl 非法（非 http(s)）⇒ 拒绝并提示；apiKey 为空 ⇒ 允许（有些本地端点不需要 key）但提示可能失败；contextLen 填 0/负数/超大 ⇒ 归一或拒绝并说明；dailyLimit 填 0 ⇒ 视为"0"而非"空"（与"空=不限"区分开，需有测试钉住）；掩码控件切换不触发保存、不失焦丢失输入。 |
| **依赖与阻塞** | 与卡 20（代理修复）**互斥执行**：本卡必须在卡 20 落地后开工（避免同仓并发改 `src/main`、`preload`、`shared/types`）。测试连接的"走代理"依赖卡 20 的结论（若卡 20 改了 session 应用时机，本卡要保证自己的请求也走同一条路）。 |
