# 11 · verify-real-window（实机联调证据：透明/穿透/CPU/边缘/设置页/开关）

| 字段 | 内容 |
| --- | --- |
| **目标** | 在**本机装好的 obox** 上把宿主能力与扩展拼起来实测，产出可复核证据：① 安装 `.oix` 后宠物窗体自动出现在主显示器右下角；② **空白区完全透出桌面**（像素判据）；③ 空白区点击落到桌面、命中精灵/面板时可交互（穿透切换生效）；④ toggle 关 ⇒ 窗体**被销毁**且 CPU 回落，toggle 开 ⇒ 重建且状态连续；⑤ 上游 webp 精灵边缘无白边（N8）；⑥ 设置页三行进度条 + `{cur}/100` + 无描述、写后当帧刷新；⑦ 五种交互与气泡/动画按 D-4 表现；⑧ 停用扩展 ⇒ 窗体回收、无残留定时器。 |
| **输入** | `specs/pet-window/spec.md`（三条 requirement 的全部 scenario，尤其「窗体空白区完全透出桌面」的像素判据、「停用或卸载即回收窗体」）、`specs/pet-settings/spec.md`（三行进度条与当帧刷新）、`specs/pet-interaction/spec.md`、`specs/pet-sprites/spec.md`（缺帧容错、销毁即停帧循环）；`design.md` D-1/D-2/D-4/D-7/D-9/D-11（**测量透明度时不得开 DevTools**）、`## UX 与交互流程`（键盘可达性：Tab 顺序、焦点归还、Esc 只关面板）；`notes/validation.md` N6/N8（用户裁定"接受风险并登记"的两项证据）与卡 01 的判据基线。 |
| **文件所有权** | `openspec/changes/pet-desktop-companion/notes/evidence/real-window.md`（新建，含截图路径与数值）。**不改任何实现文件**；若发现缺陷，写进本证据文件的"缺陷清单"并交回 `dev`（第 7 步）修，不在本卡内改代码。 |
| **验收命令** | 证据文件须逐项给出可复核数据：① 窗体位置/尺寸截图 + `workArea` 数值与 24px 边距核对；② 取色点 RGB vs 壁纸取样（差值 ≤ 2/255，且不是 `#1e1e1e`/`#ffffff`），并附"同点在同壁纸上无窗体时"的对照值；③ 穿透验证：空白区点击命中桌面（例如点中桌面图标/右键菜单弹出），命中精灵时面板出现；④ CPU：关窗前/后各一个数值（同一测量时长与负载），并附窗体销毁的进程/窗口计数证据；⑤ 精灵边缘放大截图（无白边，或记录白边宽度与处置：改 PNG / 内缩 1px）；⑥ 设置页截图 + `{cur}/100` 文本与条宽一致性（用 `cur=99.9` 的构造值验一次取整口径）；⑦ 交互逐项记录（气泡文案、动画轨、库存与属性变化）；⑧ 停用扩展后窗口计数归零、`[pet]` 日志无后续 tick。 |
| **依赖与阻塞** | 依赖 **03、04、07、08、09、10**（宿主能力 + 扩展全部产物 + `.oix`）。**阻塞** 第 8 步 `obox-ext-check` 的"实机证据"项（check 会核对本卡证据）。 |
